Privacy policy

Eliezer · effective October 7, 2026

Eliezer is a private personal assistant used only by its owner. It is not offered to the public, and the only Google accounts that can authorize it are the owner's own.

What Eliezer accesses

  • Gmail (Google scope gmail.modify), in the owner's own accounts only: it searches and reads messages, applies labels, and creates drafts. It sends email only to the owner's own address (a daily summary and answers to the owner's requests). It never sends email to anyone else, and it does not delete messages.
  • Calendars the owner has connected, to read the schedule and to add or change events it created.

How the data is used

  • Only to perform tasks for the owner: summarizing what needs attention, preparing drafts for the owner to review and send, keeping the owner's calendar and planning notes current.
  • Email content is processed by an AI model (Anthropic's Claude) to carry out those tasks. It is not used to train models and is not used for advertising.
  • Short working notes (for example, which vendors have replied) are kept in a private repository that only the owner can access.

What Eliezer never does

  • It does not sell, rent or share Google user data with anyone.
  • It does not use Google user data for advertising, credit decisions or any purpose other than serving the owner.
  • It does not let anyone other than the owner read the data.

Google API Services User Data Policy

Eliezer's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage, security and deletion

  • Sign-in tokens are stored in the owner's device keychain and in a private, access-restricted cloud environment controlled by the owner.
  • The owner can revoke access at any time at myaccount.google.com/permissions; Eliezer then loses all access immediately. Working notes can be deleted by the owner at any time.

Changes and contact

If this policy changes, the effective date above will change. Questions can be sent to the developer contact shown on Eliezer's Google sign-in screen.
